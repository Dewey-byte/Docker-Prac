How this page is running

This site is a static cafe page packed into a Docker image based on nginx:alpine. The container serves port 80. The host maps that port so browsers — including yours — can reach it.

  1. Dockerfile describes the image
  2. docker build creates the image
  3. docker run starts a container
  4. The image is pushed to Docker Hub
  5. A public host exposes the container to the internet
